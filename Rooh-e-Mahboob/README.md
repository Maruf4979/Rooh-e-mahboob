# Rooh-e-Mahboob

Brand application architecture and project structure.

## Folder Hierarchy

```
Rooh-e-Mahboob/
├── frontend/        # Complete Next.js frontend application (no backend or external API dependencies)
├── backend/         # Dedicated directory for your custom backend server
├── database/        # Dedicated directory for your database schemas, migrations, and scripts
└── Documentation/   # Brand guidelines, PRD, and application guides
```

### Running the Frontend
```bash
cd frontend
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.
